# AngleFinder — 竞品视觉分析

## 竞品 1: Angle Meter (angle-meter.github.io)

- **主色调**: 准白色 / 浅灰色背景
- **深色 / 浅色**: 浅色
- **字体**: 系统默认无衬线体（sans-serif）
- **Hero 策略**: 无明确 Hero 区，直接放一个大型半圆量角器 Canvas
- **布局**: 居中单列，无导航，无页脚
- **CTA 文案**: 无 CTA，直接展示工具
- **整体感觉**: 纯粹的 GitHub Pages 个人项目，零设计
- **可借鉴**: 量角器的直接展示方式（首屏就是工具）
- **必须避开**: 无导航、无品牌、无移动端优化、简陋白底黑字

## 竞品 2: Calculator.net (calculator.net/right-triangle-calculator.html)

- **主色调**: 白色背景 + 蓝色链接 (#3366CC 系)
- **深色 / 浅色**: 浅色
- **字体**: Arial / Verdana 老旧系统字体
- **Hero 策略**: 无 Hero，直接是广告条 + 计算器表单
- **布局**: 两栏布局（左侧导航 + 右侧内容），但极其密集
- **CTA 文案**: "Calculate"（基础按钮）
- **整体感觉**: 2000 年代的通用计算器网站，广告密集，无设计感
- **可借鉴**: 计算功能完整、支持多种输入模式
- **必须避开**: 密集按钮风、广告过多、无移动端适配、无视觉量角器

## 竞品 3: Pixozone (pixozone.com/angle-calculator)

- **主色调**: 白色 / Wix 模板默认配色
- **深色 / 浅色**: 浅色
- **字体**: 系统默认字体
- **Hero 策略**: Wix 模板头图 + 标题
- **布局**: 居中单列，模板感强烈
- **CTA 文案**: 上传按钮
- **整体感觉**: Wix 建站，加载慢，功能单一，模板感
- **可借鉴**: 图片上传 + 点击测角的交互流程
- **必须避开**: Wix 模板感、加载慢、移动端体验差

## 竞品总结

| 维度 | 竞品1 | 竞品2 | 竞品3 | 结论 |
|---|---|---|---|---|
| 背景 | 白/灰 | 白色 | 白色 | **全部浅色**—有深色差异化空间 |
| 主色 | 无 | 蓝色 | 无 | 全部不是蓝就是无色 | 蓝色已被用烂 |
| 字体 | 系统默认 | Arial | 系统默认 | 全部低级字体 | 有大量字体升级空间 |
| Hero | 无 | 无 | 模板头图 | 无人做好首屏设计 | 首屏是最大机会 |
| 布局 | 居中单列 | 两栏密集 | 居中单列 | 全部传统布局 | Split / 非对称 / Bento 都是机会 |
| 移动端 | 一般 | 差 | 差 | 全部移动端体验不足 | 移动端是核心竞争力 |

## 设计决策

1. **竞品都是浅色 → 可以考虑深色主题形成强烈差异**
2. **竞品都是蓝色或无色 → 避开蓝色，选青/绿/橙系**
3. **竞品 Hero 都很弱 → 首屏是最大机会，必须做好**
4. **竞品布局传统 → 用 Split / 非对称 / 工具嵌入式 Hero**
5. **竞品移动端差 → 移动端是核心竞争力**
