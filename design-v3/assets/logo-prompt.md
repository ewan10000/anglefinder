# AngleFinder — Logo SVG Prompt

为 AngleFinder 设计一个 SVG 矢量 Logo icon。

要求：
- 输出原始 SVG 代码，不要图片
- 单色，主色使用 #1B4332 (方向 A) 或 #00E5CC (方向 B) 或 #2B2D42 (方向 C)
- viewBox="0 0 64 64"
- 几何化设计，从圆/方/三角/线条出发
- 16px 仍可辨识
- 只有一个记忆点
- 无渐变、无阴影、无 3D
- 产品概念：在线角度测量工具，量角器 + 计算器 + 图片测量

设计方向：
一个简化的半圆量角器，带有一条从圆心延伸到圆弧的线条（代表角度指针）。半圆上有简化的刻度线（0°、90°、180°三个主要刻度）。整体是一个结构清晰的几何图形，在小尺寸下仍然可辨识是"角度/量角器"。

备选概念：
- 三角形内部含有角度弧度标记
- 圆规 + 单一尖角指针
- 交叉的两条线段形成一个角度

建议用代码实现，而非 AI 生成图片。
