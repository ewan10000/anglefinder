# AngleFinder — Desktop Homepage v3: Warm Editorial

Design a light warm-theme landing page for AngleFinder — the most accurate and beautiful online angle finder.

Target users: Students, DIY enthusiasts, professionals.

Design vibe: Editorial / Magazine-like / Warm premium. Keywords: refined, approachable, beautiful, trustworthy, crafted.

Typography:
Use Sora for headings (geometric, clean, modern).
Use Outfit for body text (humanist, warm).
Do not use Inter, Roboto, Arial.

Color scheme:
Background: #F7F5F0 (warm white)
Surface: #FFFFFF
Primary accent: #2B2D42 (deep blue-gray)
CTA / highlight: #D8572A (burnt orange)
Text primary: #2B2D42
Text secondary: #6C757D
Border: #E8E4DE
Protractor arc: #2B2D42 at 50% opacity
Protractor pointer: #D8572A

Page structure:

1. NAVIGATION
- Fixed top bar, height 72px, bg #F7F5F0, no border (clean).
- Left: "AngleFinder" (Sora, 20px, weight 600, #2B2D42) + small geometric icon.
- Center: Nav links (Outfit, 15px, #6C757D, hover #2B2D42, letter-spacing 0.02em).
- Right: CTA "Start Measuring — Free" (bg #D8572A, text white, rounded-full, Outfit, 14px).

2. HERO SECTION
- Layout: Asymmetric split. Left 50% large text, right 50% tool card with generous whitespace.
- Left:
  - H1: "Measure Any Angle. Instantly." (Sora, 52px, weight 700, #2B2D42, tight line-height 1.05)
  - Subhead: "Online protractor, angle calculator, and image measurer — all free, no signup." (Outfit, 18px, #6C757D, line-height 1.6)
  - Disclaimer: "Results are for educational and general use only." (Outfit, 12px, #ADB5BD)
  - CTA group: Primary "Start Measuring — Free" (bg #D8572A, white, rounded-full) + Secondary "Try the Calculator" (border 1px #E8E4DE, #2B2D42, rounded-full)
  - Trust line with small checkmark.
- Right:
  - White card (bg white, subtle shadow, border-radius 20px) with tool tabs.
  - Tabs: "Protractor", "Calculator", "Image" (soft pill style, active: bg #2B2D42 + white text).
  - Protractor display: Elegant thin-line protractor, orange pointer. Large "127°" (Sora, 56px, #2B2D42).
- Background: #F7F5F0 with very subtle warm texture.

3. HOW IT WORKS

- Padding: 120px 0
