# AngleFinder — SEO Matrix Page Template

Use this template for all SEO sub-pages (/complementary-angle, /supplementary-angle, /blog/*, etc.).

## Reusable Elements (copy from homepage)
- Navigation (same component)
- Footer (same component)
- Cookie banner (same component)
- Color scheme: Background #FAFAFA, primary #1B4332, accent #E63946, text #1A1A1A
- Fonts: Space Grotesk, DM Sans, JetBrains Mono
- Card styles: bg white, border 1px #E5E7EB, border-radius 12px
- Button styles: primary rounded-full, secondary border rounded-full

## Per-Page Changes
- Page title (H1): Target keyword first
- Subhead: Keyword-related description
- Content: 800-1500 words of educational content
- Embedded mini-tool: Relevant calculator or protractor variant
- FAQ: 3-5 questions specific to the keyword
- Internal links: Link to homepage, related tools, related articles
- Schema.org: Article or SoftwareApplication markup (no fake ratings)

## Layout Pattern
1. NAVIGATION
2. HERO (H1 + subhead + breadcrumb)
3. QUICK ANSWER / TOOL (if applicable)
4. MAIN CONTENT (structured with H2/H3, bullet points, tables)
5. VISUAL DIAGRAMS (SVG illustrations)
6. FAQ
7. RELATED CONTENT
8. FOOTER

## SEO Meta Template
- Title: [Keyword] — [Brief Description] | AngleFinder
- Description: 150-160 chars, include keyword, mention free tool, no signup.
- OG Title: [Keyword] — Free Online Tool
- OG Description: Same as meta description.
